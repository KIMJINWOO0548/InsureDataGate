# Existing design, clearer investigation scope

The report retains its existing neutral system font, local gate header, offline navigation and dossier styles. General metadata-summary→detail patterns are adapted independently; no reference brand or asset is shipped.

- Exposure table: snapshot and direct/source-only are separate column headings. Caption narrows the population to changed/linked cases, and split links open a clearly labelled native view.
- Scope disclosure: one native initially closed44px control contains all obligation counts, matrix and definitions; case split filters stay outside. This consistent hierarchy preserves a useful first dossier on mobile.
- Review obligations: four numeric definitions with explicit overlap; gold changes exclude lifecycle additions/removals and no number is labelled completed/approved.
- Split views: case scope across either snapshot. Sources are reached through retained relationship links in All items; no mixed case/source count is labelled as case count.
- Large directory: bounded optional preview, explicit full-list notice, complete native dossier destinations, no JavaScript.
- Long report: native offscreen rendering optimization and print-all; no hidden evidence from a collapsed disclosure that a fragment cannot reach.
- Colors: existing own palette recorded in `tokens.json`; actual Replica contrast check≥4.5text and≥3focus. Native keyboard/real geometry are separate browser checks.
