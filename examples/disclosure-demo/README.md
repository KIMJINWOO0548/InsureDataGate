# Fictional disclosure extraction 0.1.0

This is the baseline of one synthetic, domain-neutral disclosure extraction dataset. Every issuer, excerpt, amount and identity is invented. Six cases use the existing manifest.v1 contract, with separate case/gold files and two cases per split. The checker validates release consistency, not extraction correctness or authenticated review.

See [the workflow and limitations](../../docs/DISCLOSURE_EXAMPLE.md). The separate `disclosure-demo-v2` candidate changes one training example and its source note; validation/test records stay unchanged. This is not an investment or compliance tool.
